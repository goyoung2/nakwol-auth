# AUTH 0.2.9: per-app usage statistics

## Change
`/admin/apps` app details gain a **이용 통계** section for Connect managers.

- Period: 7, 30 or 90 days, Korean calendar days.
- Summary: distinct users, use sessions, access denials.
- Daily distinct-user chart with idle days shown.
- Top 50 users by use sessions, with active days and first/last use in the period.

API: `GET /admin/api/apps/:clientId/usage?days=7|30|90`, guarded by the existing Connect manager check and served with `Cache-Control: no-store`.

## Data meaning
Use sessions count existing `auth_events` of type `discord.login.success`, `authorize.sso` and `authorize.sso_auto`; denials count `authorize.access_denied` and `discord.login.access_denied`. These are login/SSO events, not page views: with one-hour gate sessions an active user adds roughly one session per hour.

No migration. Statistics cover existing history immediately after deployment. Connect, Web SDK and DATA versions are unchanged; no site reinstall or npm publication is required.
