# AUTH 0.2.5: Cloudflare Discord login recovery

Production source: `1eae1b8301be91b0a79497747abdeaa0b5b6d36e`.

## Incident and repair
The Discord transport used `redirect: error`. Cloudflare workerd rejected that RequestInit before sending the request, mapped by the transport to `DISCORD_TOKEN_NETWORK`. Repeated login retries therefore could not recover. Existing SSO sessions could still work, concealing the failure in health/page checks.

Use `redirect: manual` and retain the existing rejection of non-success HTTP responses. Redirects are not followed. Deadlines, body limits, membership policies and session behavior are unchanged. The defect predates the qualification-management release.
